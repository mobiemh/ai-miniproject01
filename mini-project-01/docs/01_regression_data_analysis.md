## 2. 데이터 분할 및 누수 확인 (CP-02)

- **Train:** 2011-01-01T00:00:00.000000 ~ 2012-05-25T00:00:00.000000 / 12139건 / `cnt` 평균 159.72007578877998
- **Validation:** 2012-05-26T00:00:00.000000 ~ 2012-09-11T00:00:00.000000 / 2616건 / `cnt` 평균 281.0428134556575
- **Test:** 2012-09-12T00:00:00.000000 ~ 2012-12-31T00:00:00.000000 / 2624건 / `cnt` 평균 235.7580030487805
- **시간 순서로 분할한 이유:** 시간의 흐름에 따라 데이터가 변화하는게 중요한데 뒤섞이면 안돼서
- **`casual + registered == cnt` 확인 결과:** True
- **누수 가능성이 있어 제외한 특성과 이유:** casual와 registered를 더하면 cnt가 되는데, 이를 학습에 사용하면 정답이 입력에 포함되어 데이터 누수가 생깁니다. 그 결과 모델이 두 값이 의존하게되어 실제 예측에서는 맞지 않게 됩니다.

**분석:** 세 집합의 `cnt` 평균이 서로 다르다면, 그 차이가 이후 모델 평가에 어떤 영향을 줄지 1~2문장으로 작성합니다.  
train 데이터의 cnt 평균이 낮게 나오는데 이렇게되면 valid, test 단계에서 실제보다 낮게 예측하게됩니다.

## 4. 특성공학 및 전처리 (CP-03)

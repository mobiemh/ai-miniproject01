## 1. 데이터 탐색 및 클래스 분포 (CP-01)

- **데이터 크기:** 12330행, 18열
- **결측값 및 중복 행:** 결측값 0, 중복 125행 (중복 행을 삭제하지 않은 이유: 다른 유저가 같은 행동 패턴을 보였을수 있으므로 삭제하지 않고 유지합니다.)
- **수치형 특성 분포의 특징(`ProductRelated`, `PageValues` 등):** 여러 페이지를 보거나, 페이지에서 오래 머물거나 다양한 페이지를 보는 경우보다 특정페이지를 적게 보고 페이지에 짧게 머물면서 구매하는 사람이 많습니다. 그리고 ExitRates는 다른 특성들과 달리 0.01부근과 0.2에서 수치가 튀는형태입니다. 이탈율이 낮은곳에 세션이 몰려있다는것은 여러페이지를 둘러보았다는것이고, 높은곳에 몰린것은 페이지를 적게 보고 이탈한 세션을 의미합니다. 조금 보고 이탈하거나 아니면 여러페이지를 둘러보는 사용자로 크게 분류할수 있습니다.
- **구매(`Revenue=1`) 건수와 비율:** 1908건 / 15.47%
- **미구매(`Revenue=0`) 건수와 비율:** 10422건 / 84.53%

**분석:** 모두 미구매로 예측했을 때 Accuracy가 약 84.53%인 이유와 이 수치만으로 평가하기 어려운 점을 작성합니다.  
전체 데이터에서 미구매가 차지하는 비율이 높아서 미구매가 예측이 될 확률이 높습니다. 그래서 지금  미구매에 높은 확률이 나왔다고 해서 나중에 구매/미구매 비율이 달라졌을때도 똑같이 높은 확률이 나오리라는 보장이 없습니다.

## 2. 계층화 데이터 분할 (CP-02)

- **`stratify`를 적용한 이유:** 지정한 비율의 양으로 데이터를 분할하기위해
- **1일차 회귀의 날짜 순서 분할과 다른 이유:** 날짜는 순서를 유지해야 시간에 흐름에 따라서 달라지는 데이터를 분석,예측할수 있고, 지금은 순서와 상관없이 구매/비구매 여부를 예측하기 때문입니다.

**분석:** Train·Validation·Test의 구매 비율이 유사한지 확인하고 의미를 1~2문장으로 작성합니다.  
데이터셋의 구매 비율이 15.46%로 동일하게 분할 되었습니다. 이유는 데이터셋의 구매여부 비율이 원본 데이터와 동일해야 모델선응을 실제 데이터에 맞게 평가할 수 있기 때문입니다.
